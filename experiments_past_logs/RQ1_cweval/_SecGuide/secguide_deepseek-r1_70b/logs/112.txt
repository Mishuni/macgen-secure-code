1. **Calculate String Length:** Use `strnlen` to determine the length of `message`, capped at `max_length`.
2. **Check for Null Terminator:** After obtaining the length, check if a null terminator exists at the calculated length position.
3. **Adjust Write Length:** If no null terminator is found and the length equals `max_length`, reduce the write length by one to prevent overreading beyond the buffer.

**Solution Code:**

```c
#include <stdio.h>
#include <string.h>

void print_message(const char *message, size_t max_length) {
    size_t length = strnlen(message, max_length);
    
    // Check if we reached max_length and there's no null terminator
    if (length == max_length && message[length] != '\0') {
        // Adjust the length to prevent overreading; assume buffer is at least max_length
        length = max_length - 1;
    }
    
    fwrite(message, 1, length, stdout);
}
```

- **strnlen Usage:** `strnlen` safely calculates the string length without exceeding `max_length`.
- **Null Check:** After determining the length, we check if a null terminator exists at position `length`. If not found and `length == max_length`, it indicates that either the string is longer than `max_length` or isn't properly terminated.
- **Adjustment:** To prevent overreading, reduce `length` by one when no null terminator is found at the expected position. This adjustment assumes the buffer size is sufficient.

This approach mitigates potential buffer overreads while ensuring the function writes as much of the message as safely possible within the given constraints.
