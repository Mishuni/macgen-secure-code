To address the security concerns associated with creating temporary files, we need to ensure that the file is created in a secure location, has an unpredictable name, proper permissions, and is cleaned up in case of any errors. Here's how you can implement it:

### Approach
1. **Create a Secure Directory**: Use a fixed directory (e.g., `~/.myapp/tmp`) with restricted access permissions (`0o700`). This ensures that only the user has access.
2. **Generate Temporary File**: Utilize Python's `tempfile.NamedTemporaryFile` to create a file within this secure directory. This function generates a unique filename each time, reducing the risk of symlink attacks.
3. **Set Permissions Explicitly**: After writing data to the file, set its permissions to `0o600` to ensure only the owner can read and write.
4. **Handle Exceptions Gracefully**: If any error occurs during file creation or writing, delete the file before re-raising the exception to prevent information leakage.

### Solution Code
```python
import os
import tempfile

def write_results(results):
    temp_dir = os.path.join(os.path.expanduser('~'), '.myapp', 'tmp')
    # Create the temporary directory with secure permissions if it doesn't exist
    os.makedirs(temp_dir, mode=0o700, exist_ok=True)
    
    try:
        # Create a temporary file in the secure directory without deleting it on close
        with tempfile.NamedTemporaryFile(mode='w', delete=False, dir=temp_dir) as f:
            f.write(results)
            filename = f.name
            # Explicitly set the permissions to read/write for owner only
            os.chmod(filename, 0o600)
        
        return filename
    
    except Exception as e:
        # Clean up the file if it was created but an error occurred
        if 'filename' in locals():
            try:
                os.unlink(filename)
            except OSError:
                pass
        raise
```

- **Secure Directory Creation**: The directory `~/.myapp/tmp` is created with permissions `0o700`, ensuring only the user can access it.
- **Temporary File Handling**: Using `tempfile.NamedTemporaryFile` in this directory creates a file with a unique name each time, avoiding symlink attack risks. The `delete=False` parameter ensures the file remains after the context manager exits.
- **Permission Setting**: After writing data, `os.chmod` sets the file permissions to `0o600`, allowing only the owner to read and write.
- **Exception Handling**: If any error occurs during file operations, the file is deleted before re-raising the exception, preventing potential security issues.

This approach ensures that temporary files are handled securely, with proper access controls and cleanup mechanisms in place.

```python
import os
import tempfile
import stat

def write_results(results):
    temp_dir = os.path.join(os.path.expanduser('~'), '.myapp', 'tmp')
    
    # Create the temporary directory with secure permissions if it doesn't exist
    os.makedirs(temp_dir, mode=0o700, exist_ok=True)
    
    # Verify directory ownership and permissions
    dir_stat = os.stat(temp_dir)
    if dir_stat.st_uid != os.getuid() or (dir_stat.st_mode & 0o777) != 0o700:
        raise PermissionError("Temporary directory has insecure permissions or ownership")
    
    filename = None
    
    try:
        # Create a temporary file in the secure directory without deleting it on close
        with tempfile.NamedTemporaryFile(mode='wb', delete=False, dir=temp_dir) as f:
            f.write(results)
            filename = f.name
            # Explicitly set the permissions immediately after creation
            os.chmod(filename, 0o600)
        
        # Verify file permissions after setting them
        file_stat = os.stat(filename)
        if (file_stat.st_mode & 0o777) != 0o600:
            raise PermissionError("Temporary file has insecure permissions")
            
        return filename
    
    except Exception as e:
        # Clean up the file if it was created but an error occurred
        if filename is not None:
            try:
                os.unlink(filename)
            except OSError:
                pass
        raise
```
