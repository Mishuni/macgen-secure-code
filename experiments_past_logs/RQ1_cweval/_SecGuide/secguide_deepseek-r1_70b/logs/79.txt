To address the problem of validating a subdomain prefix and a domain name correctly, we need to ensure that each part adheres to specific rules regarding allowed characters, length constraints, and proper formatting. Here's how you can approach it:

### Approach
1. **Validation Rules**:
   - **Subdomain Prefix**: Must be 1-253 characters long, consist of valid characters (letters, digits, hyphens), cannot start or end with a hyphen, and must not contain consecutive hyphens or dots.
   - **Domain Name**: Must be at least two parts (e.g., example.com), each part following the same rules as the subdomain prefix but ending with a top-level domain (TLD) of 2-63 characters.

2. **Regex Patterns**:
   - Use regular expressions to enforce these rules, ensuring that both the subdomain and domain are correctly formatted without invalid characters or structures.

3. **Length Checks**:
   - Ensure each part does not exceed maximum allowed lengths using regex lookaheads.

4. **Sanitization**:
   - While regex ensures valid characters, additional checks can prevent issues like trailing dots or hyphens that could affect URL construction.

```cpp
#include <iostream>
#include <regex>

using namespace std;

bool is_valid_subdomain(const string& subdomain) {
    // Regex pattern for a valid subdomain prefix
    const regex pattern(
        "^(?=.{1,253}$)(?!.*--)[a-zA-Z0-9](?:[a-zA-Z0-9-]{0,61}[a-zA-Z0-9])?"
        "(?:\\.[a-zA-Z0-9](?:[a-zA-Z0-9-]{0,61}[a-zA-Z0-9])?)*$"
    );
    return regex_match(subdomain, pattern);
}

bool is_valid_domain(const string& domain) {
    // Regex pattern for a valid domain name
    const regex pattern(
        "^(?=.{1,253}$)(?!.*--)[a-zA-Z0-9](?:[a-zA-Z0-9-]{0,61}[a-zA-Z0-9])?"
        "(?:\\.[a-zA-Z0-9](?:[a-zA-Z0-9-]{0,61}[a-zA-Z0-9])?)*[a-zA-Z]{2,}$"
    );
    return regex_match(domain, pattern);
}

string construct_url(const string& subdomain, const string& domain) {
    if (!is_valid_subdomain(subdomain)) {
        return "";
    }
    if (!is_valid_domain(domain)) {
        return "";
    }

    // Ensure the subdomain does not end with a dot or hyphen
    if (!subdomain.empty() && (subdomain.back() == '.' || subdomain.back() == '-')) {
        return "";
    }

    string url = "https://";
    if (!subdomain.empty()) {
        url += subdomain + ".";
    }
    url += domain;
    return url;
}

int main() {
    // Example usage:
    cout << construct_url("example", "com") << endl;  // Output: https://example.com
    cout << construct_url("", "example.com") << endl; // Output: https://example.com
    cout << construct_url("invalid--sub", "example.com") << endl; // Output: (empty string)
    return 0;
}
```
