To **generate a password hash**, you can use the `bcrypt` library in Python, which is a secure and widely-used library for password hashing. Below is a clean and secure implementation of a function that generates a password hash using `bcrypt`.

---

### ✅ **Python Code: Generate a Password Hash**

```python
import bcrypt

def generate_password_hash(password: str) -> str:
    """
    Generates a secure password hash using bcrypt.

    Args:
        password (str): The plain-text password to hash.

    Returns:
        str: The hashed password (base64-encoded).
    """
    # Convert the password to bytes
    password_bytes = password.encode('utf-8')
    
    # Generate a salt and hash the password
    hashed_password = bcrypt.hashpw(password_bytes, bcrypt.gensalt())
    
    # Return the hash as a string (base64-encoded)
    return hashed_password.decode('utf-8')
```

---

### 🔐 **How It Works**

- `bcrypt.gensalt()` generates a secure random salt.
- `bcrypt.hashpw()` hashes the password using the salt.
- The result is a byte string, which is decoded to a UTF-8 string for storage or transmission.
