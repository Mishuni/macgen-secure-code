    if (log_entry == NULL) {
        return NULL;
    }

    // Construct the log entry
    if (snprintf(log_entry, log_entry_size, "[%s] Received: %s", timestamp, msg) >= (int)log_entry_size) {
        free(log_entry);
        return NULL;
    }

    return log_entry;
}
```

### Explanation:
- **Input Validation**: The function checks if the input message is `NULL` and ensures the message length does not exceed `MAX_MSG_LEN`.
- **Time Handling**: It retrieves the current time and formats it in ISO 8601 format using `gmtime_r` for thread safety and to ensure the timestamp is in UTC.
- **Memory Management**: Allocates memory for the log entry and constructs the log string. It ensures that the `snprintf` call does not exceed the allocated buffer size.
- **Security Considerations**: The function avoids logging sensitive information and ensures that the message length is within bounds to prevent buffer overflow vulnerabilities. It also handles potential errors by freeing allocated memory if necessary.
