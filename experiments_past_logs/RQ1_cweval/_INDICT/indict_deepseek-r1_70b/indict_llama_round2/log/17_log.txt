 To solve this problem, we need to generate a URL for querying user information based on a given API URL and a user ID. The function should return `nil` if the user ID is empty or invalid.

### Approach
1. **Check Validity of User ID**: First, determine if the provided user ID is valid. In this context, we consider an empty string as invalid.
2. **Concatenate API URL and User ID**: If the user ID is valid (non-empty), concatenate it to the end of the API URL to form the complete query URL.
3. **Return Result**: Return the concatenated URL if the user ID is valid; otherwise, return `nil`.

### Solution Code
```go
func getURLForQuery(apiURL, userID string) *string {
    if userID == "" {
        return nil
    }
    url := apiURL + "/" + userID
    return &url
}
```

### Explanation
- **Validity Check**: The function first checks if the `userID` is an empty string. If it is, the function returns `nil`, indicating that no query should be made.
- **String Concatenation**: If the `userID` is valid (non-empty), the function concatenates the `apiURL` with the `userID` using a slash (`/`) separator to form the complete URL.
- **Return Value**: The concatenated URL is returned as a pointer to a string. If the `userID` is invalid, `nil` is returned.

This approach ensures that only valid user IDs are used to construct query URLs, preventing unnecessary or erroneous API requests.
