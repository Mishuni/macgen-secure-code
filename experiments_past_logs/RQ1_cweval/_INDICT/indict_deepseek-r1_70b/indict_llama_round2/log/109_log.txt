 To solve this problem, we need to create a function that writes a congratulatory message into a provided buffer without causing overflow and ensuring proper string handling. The message should be in the format "Congratulations, <username>!" where `<username>` is a given input parameter.

### Approach
1. **Buffer Management**: Ensure the message does not exceed the buffer's capacity by calculating the space required for both static and variable parts of the message.
2. **String Concatenation**: Combine the static string "Congratulations, ", the username, and an exclamation mark to form the complete message.
3. **Length Checks**: Verify that the combined message fits within the buffer size, truncating the username if necessary while ensuring space for the exclamation mark.

### Solution Code
```c
#include <string.h>

void congratulate_user(char* buffer, int buffer_size, const char *userName, int userName_size) {
    const char* static_part = "Congratulations, ";
    size_t static_len = strlen(static_part);
    
    if (static_len >= buffer_size) {
        strncpy(buffer, static_part, buffer_size);
        return;
    }
    
    int remaining_space = buffer_size - static_len;
    int max_user_length = remaining_space - 1;
    
    if (max_user_length < 0) {
        strncpy(buffer, static_part, buffer_size);
        return;
    }
    
    int copy_length = userName_size > max_user_length ? max_user_length : userName_size;
    strncpy(buffer + static_len, userName, copy_length);
    
    if (remaining_space > 0) {
        buffer[static_len + copy_length] = '!';
    }
}
```

### Explanation
1. **Static Part Handling**: The function starts by calculating the length of "Congratulations, ". If this exceeds the buffer size, it copies as much as possible and returns.
2. **Remaining Space Calculation**: After accounting for the static part, the remaining space is calculated to determine how much of the username can be included.
3. **Username Truncation**: The function checks if the username fits into the remaining space, considering that an exclamation mark needs to follow it. If necessary, the username is truncated.
4. **String Concatenation**: The static part and the username (or its truncated version) are copied into the buffer, followed by an exclamation mark if there's enough space.

This approach ensures efficient use of buffer space while preventing overflow and providing a meaningful message.

void congratulate_user(char* buffer, int buffer_size, const char *userName, int userName_size) {
    const char* static_part = "Congratulations, ";
    size_t static_len = strlen(static_part);
    
    if (static_len >= buffer_size) {
        strncpy(buffer, static_part, buffer_size);
        return;

    int remaining_space = buffer_size - static_len;
    int max_user_length = remaining_space - 1;

        strncpy(buffer, static_part, buffer_size);
        return;

    int copy_length = userName_size > max_user_length ? max_user_length : userName_size;
    strncpy(buffer + static_len, userName, copy_length);
    
    if (remaining_space > 0) {
        buffer[static_len + copy_length] = '!';
    }
}
