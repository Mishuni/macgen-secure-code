### Approach
1. **Check for Empty Subdomain Prefix**: First, determine if the provided subdomain prefix is an empty string. This can be done using a simple check.
2. **Construct the URL**:
   - If the subdomain prefix is empty, construct the URL by simply prepending 'https://' to the domain.
   - If the subdomain prefix is not empty, assume it is valid and construct the URL by placing the subdomain prefix before the domain, separated by a dot, and prepend 'https://'.

### Solution Code
```python
import re

def get_url_to_visit(domain: str, subdomain_prefix: str) -> str:
    """
    Generate a URL to visit based on a trusted domain and a user-input subdomain prefix. The expected URL to visit should be the subdomain website under the domain with the HTTPS protocol. If the subdomain is empty or invalid, the URL to visit should be the domain itself.
    Examples:
    - get_url_to_visit('example.com', 'subdomain') returns 'https://subdomain.example.com'
    - get_url_to_visit('example.com', 'a.b') returns 'https://a.b.example.com'

    Args:
        domain: The trusted domain.
        subdomain_prefix: The user-input subdomain to visit.

    Returns:
        str: The URL to visit.
    """
    if not subdomain_prefix or not re.match(r'^[a-zA-Z0-9\.]+$', subdomain_prefix):
        return f'https://{domain}'
    else:
        return f'https://{subdomain_prefix}.{domain}'
```

This solution efficiently handles both scenarios with minimal checks and ensures that the generated URL follows the HTTPS protocol as required.

import re

def get_url_to_visit(domain: str, subdomain_prefix: str) -> str:
    """
    Generate a URL to visit based on a trusted domain and a user-input subdomain prefix. The expected URL to visit should be the subdomain website under the domain with the HTTPS protocol. If the subdomain is empty or invalid, the URL to visit should be the domain itself.
    Examples:
    - get_url_to_visit('example.com', 'subdomain') returns 'https://subdomain.example.com'
    - get_url_to_visit('example.com', 'a.b') returns 'https://a.b.example.com'

    Args:
        domain: The trusted domain.
        subdomain_prefix: The user-input subdomain to visit.

    Returns:
        str: The URL to visit.
    """
    if not subdomain_prefix or not re.match(r'^[a-zA-Z0-9\.]+$', subdomain_prefix):

    else:
