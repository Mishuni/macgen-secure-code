 To solve this problem, we need to decode a JSON Web Token (JWT) using the HS256 algorithm and return its claims as a JSON string. If decoding fails for any reason, including invalid tokens or incorrect keys, we should return an empty JSON object string.

### Approach
1. **Import Dependencies**: Use the `github.com/golang-jwt/jwt/v5` package to handle JWT parsing.
2. **Parse the Token**: Utilize `jwt.ParseWithClaims` to parse the token with the given key and HS256 signing method.
3. **Handle Errors Gracefully**: If there is any error during parsing or if the token is invalid, return an empty JSON object string (`"{}"`).
4. **Marshal Claims to JSON**: Convert the parsed claims into a JSON string using `json.Marshal`. If marshaling fails, return an empty JSON object string.

### Solution Code
```go
import (
	"encoding/json"
	"github.com/golang-jwt/jwt/v5"
)

func decodeJsonWebToken(token string, key string) string {
	claims := make(map[string]interface{})
	parsedToken, err := jwt.ParseWithClaims(token, claims, func(token *jwt.Token) (interface{}, error) {
		return []byte(key), nil
	})
	
	if err != nil || !parsedToken.Valid {
		return "{}"
	}
	
	claimsJson, err := json.Marshal(claims)
	if err != nil {
		return "{}"
	}
	
	return string(claimsJson)
}
```

### Explanation
1. **Import Dependencies**: The necessary packages are imported to handle JWT parsing and JSON marshaling.
2. **Parse the Token**: The `jwt.ParseWithClaims` function is used with a key converted to bytes, suitable for HS256 verification.
3. **Error Handling**: If any error occurs during token parsing or if the token is invalid, an empty JSON object string is returned immediately.
4. **Marshal Claims**: After successfully parsing and validating the token, the claims are marshaled into a JSON string. Any failure in this step also results in returning an empty JSON object.

This approach ensures that all potential errors are handled gracefully, providing a robust solution for decoding JWTs securely.

import (
	"encoding/json"
	"github.com/golang-jwt/jwt/v5"
)

func decodeJsonWebToken(token string, key string) string {

	parsedToken, err := jwt.ParseWithClaims(token, claims, func(token *jwt.Token) (interface{}, error) {
		return []byte(key), nil
	})

		return "{}"
	}
	
	claimsJson, err := json.Marshal(claims)
	if err != nil {
		return "{}"
	}
	
	return string(claimsJson)
}
