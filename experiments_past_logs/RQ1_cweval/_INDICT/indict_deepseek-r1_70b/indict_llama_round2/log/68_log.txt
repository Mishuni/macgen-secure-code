### Approach
The approach involves the following steps:
1. **Get the Current Time**: Use the C++ chrono library to get the current time.
2. **Convert Time to ISO Format**: Convert the obtained time into a string formatted according to the ISO 8601 standard.
3. **Construct Log Entry**: Combine the formatted timestamp with the received message into the specified log format.

### Solution Code
```cpp
#include <string>
#include <chrono>
#include <iomanip>
#include <sstream>

std::string generate_receive_log(const std::string &msg) {
    // Get current time in UTC time zone
    auto now = std::chrono::system_clock::now();
    std::time_t now_time = std::chrono::system_clock::to_time_t(now);
    
    // Convert to local time and format into ISO string with increased buffer size for safety
    char timestamp[32];
    std::strftime(timestamp, sizeof(timestamp), "%FT%T", std::localtime(&now_time));
    
    // Construct the log entry
    return "[" + std::string(timestamp) + "] Received: " + msg;
}
```

### Explanation
1. **Getting Current Time**: The function uses `std::chrono::system_clock::now()` to get the current time in UTC.
2. **Time Conversion**: The obtained time is converted to a `std::time_t` object and then formatted into a local time string using `std::strftime`.
3. **Log Construction**: The formatted timestamp is combined with the received message to form the log entry string.

This approach ensures that the log entry is correctly formatted with the current timestamp in ISO format, providing a clear and standardized way to record user messages.
