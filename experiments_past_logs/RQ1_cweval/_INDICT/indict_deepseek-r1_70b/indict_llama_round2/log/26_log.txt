### Approach
1. **Generate Key Pair**: Use the `crypto.generateKeyPairSync` method to create a new RSA key pair. This method is synchronous, which means it will block the event loop until the operation completes.
2. **Modulus Length**: Set the modulus length to 2048 bits, which is considered secure for RSA keys.
3. **Public Exponent**: Use the public exponent value of 65537, a commonly used and secure choice for RSA.
4. **Key Encoding**: Encode both the private and public keys in PEM format. The private key will use PKCS#1 encoding, while the public key uses SPKI (Subject Public Key Information) encoding.

### Solution Code
```javascript
const crypto = require('crypto');

/**
 * Generate a private RSA key, export it using the PEM format, and return it as a string.
 *
 * @returns {string} The RSA private key in PEM format.
 */
function create_private_key() {
    // Create a new RSA key pair with specified configurations
    const key = crypto.generateKeyPairSync('rsa', {
        modulusLength: 2048,
        publicExponent: 65537,
        publicKeyEncoding: {
            type: 'spki',
            format: 'pem'
        },
        privateKeyEncoding: {
            type: 'pkcs1',
            format: 'pem'
        }
    });

    // Return the private key in PEM format
    return key.privateKey;
}
```

- **Security**: The chosen modulus length (2048 bits) and public exponent (65537) are industry standards for secure RSA keys, ensuring the generated key is robust against common attacks.
