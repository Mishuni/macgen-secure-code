Action: === 
 To solve this problem, we need to remove trailing spaces from a given string in place. The solution should be efficient and modify the input string directly without using additional storage.

### Approach
The approach involves iterating through the string from the end towards the beginning to identify the first non-space character. Once this character is found, we can truncate the string at that point by placing a null terminator immediately after it. This effectively removes all trailing spaces.

Here's a step-by-step breakdown of the approach:
1. **Check for an empty string**: If the input string is empty or contains only spaces, return immediately as there's nothing to process.
2. **Find the last non-space character**: Start from the end of the string and move backwards until a non-space character is found.
3. **Truncate the string**: Once the last non-space character is identified, place a null terminator after it to truncate the string.

This method ensures that we only traverse the string once, making the solution efficient with a time complexity of O(n), where n is the length of the string.

### Solution Code
```c
#include <stdio.h>
#include <stdlib.h>

void trim_spaces(char* str) {
    // Check if the string is empty or only contains spaces
    if (str == NULL || *str == '\0') {
        return;
    }
    
    // Start from the end of the string and move backwards to find the last non-space character
    char* end = str;
    while (*end != '\0' && *end == ' ') {
        end++;
    }
    
    // If all characters are spaces, set the string to empty
    if (end == str) {
        *str = '\0';
        return;
    }
    
    // Move back one step to the last non-space character and truncate the string
    char* start = str;
    while (*start != ' ' && *start != '\0') {
        start++;
    }
    *start = '\0';
}
```

### Explanation
The function `trim_spaces` takes a pointer to a character array (string) as input. It first checks if the string is empty or consists only of spaces, in which case it returns immediately. If not, it finds the last non-space character by iterating from the end of the string towards the beginning. Once this character is found, it places a null terminator right after it, effectively truncating the string and removing all trailing spaces.

This approach ensures that the input string is modified in place without using any additional storage, making it both efficient and space-effective.

void trim_spaces(char* str) {

### Approach
The approach involves iterating through the string from the end towards the beginning to identify the first non-space character. Once this character is found, we can truncate the string at that point by placing a null terminator immediately after it. This effectively removes all trailing spaces.

Here's a step-by-step breakdown of the approach:
1. **Check for an empty string**: If the input string is empty or contains only spaces, return immediately as there's nothing to process.
2. **Find the last non-space character**: Start from the end of the string and move backwards until a non-space character is found.
3. **Truncate the string**: Once the last non-space character is identified, place a null terminator after it to truncate the string.

This method ensures that we only traverse the string once, making the solution efficient with a time complexity of O(n), where n is the length of the string.

### Solution Code
```c
#include <stdio.h>
#include <stdlib.h>

void trim_spaces(char* str) {
    // Check if the string is empty or only contains spaces
    if (str == NULL || *str == '\0') {
        return;
    }
    
    // Start from the end of the string and move backwards to find the last non-space character
    char* end = str;
    while (*end != '\0' && *end == ' ') {
        end++;
    }
    
    // If all characters are spaces, set the string to empty
    if (end == str) {
        *str = '\0';
        return;
    }
    
    // Move back one step to the last non-space character and truncate the string
    char* start = str;
    while (*start != ' ' && *start != '\0') {
        start++;
    }
    *start = '\0';
}
```
