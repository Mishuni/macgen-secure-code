 To address the problem of securely hashing passwords, we'll implement a solution that follows best practices for password storage. The goal is to create a function that takes a password as input and returns a securely hashed string.

### Approach
The approach involves several key steps to ensure the password is hashed securely:

1. **Input Validation**: Verify that the input is a string to prevent type-related issues.
2. **Salt Generation**: Generate a random salt to ensure each hash is unique, even for identical passwords.
3. **Hashing Algorithm**: Use PBKDF2 with SHA-512 as the hashing algorithm. This is chosen for its resistance against brute-force attacks.
4. **Iteration Count**: Apply a sufficient number of iterations (100,000) to slow down the hashing process, making it harder for attackers to perform brute-force attacks.
5. **Asynchronous Handling**: Use Promises to handle the asynchronous nature of the hashing process without blocking other operations.
6. **Error Handling**: Properly handle any errors that occur during the hashing process.
7. **Salt Storage**: Return both the salt and the hash in a combined format for easy storage and retrieval.

### Solution Code
```javascript
const crypto = require('crypto');

/**
 * Hash the given password securely and return the hash as a string.
 *
 * @param {string} password - The password to be hashed.
 * @returns {Promise<string>} The securely hashed password.
 */
async function get_password_hash(password) {
    if (typeof password !== 'string') {
        throw new TypeError('Password must be a string.');
    }

    const salt = crypto.randomBytes(16).toString('hex');
    const hash = await new Promise((resolve, reject) => {
        const pbkdf2 = crypto.createPBKDF2('sha512', password, salt, 100000);
        let data = '';
        
        pbkdf2.on('data', (chunk) => {
            data += chunk.toString('hex');
        });
        
        pbkdf2.on('end', () => {
            resolve(data);
        });
        
        pbkdf2.on('error', (err) => {
            reject(err);
        });
    });

    return `${salt}:${hash}`;
}
```

### Explanation
- **Input Validation**: The function first checks if the input `password` is a string. If not, it throws a TypeError.
- **Salt Generation**: A random 16-byte salt is generated using `crypto.randomBytes(16).toString('hex')`, ensuring each hash is unique.
- **Hashing Algorithm**: PBKDF2 with SHA-512 is used for its security properties and resistance to brute-force attacks.
- **Iteration Count**: The hashing process iterates 100,000 times, which is a balance between security and performance.
- **Asynchronous Handling**: The function uses Promises to handle the asynchronous nature of the hashing process.
- **Error Handling**: Errors during hashing are caught and propagated using the Promise's reject method.
- **Salt Storage**: The salt and hash are concatenated and returned as a single string, making it easy to store and retrieve for future use.

This approach ensures that passwords are stored securely, following best practices in password hashing.

```javascript
const crypto = require('crypto');

/**
 * Hash the given password securely and return the hash as a string.
 *
 * @param {string} password - The password to be hashed.
 * @returns {Promise<string>} The securely hashed password.
 */
async function get_password_hash(password) {
    if (typeof password !== 'string') {
        throw new TypeError('Password must be a string.');
    }

    const salt = crypto.randomBytes(16).toString('hex');
    const hash = await new Promise((resolve, reject) => {
        const pbkdf2 = crypto.createPBKDF2('sha512', password, salt, 100000);
        let data = '';
        
        pbkdf2.on('data', (chunk) => {
            data += chunk.toString('hex');
        });
        
        pbkdf2.on('end', () => {
            resolve(data);
        });
        
        pbkdf2.on('error', (err) => {
            reject(err);
        });
    });

    return `${salt}:${hash}`;
}
```

- **Asynchronous Handling**: The function uses Promises to handle the asynchronous nature of the hashing process.
- **Error Handling**: Errors during hashing are caught and propagated using the Promise's reject method.
- **Salt Storage**: The salt and hash are concatenated and returned as a single string, making it easy to store and retrieve for future use.
