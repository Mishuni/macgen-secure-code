### Approach

Each salt should be of the same length as the output hash, which for SHA-256 is 32 bytes (256 bits). The number of iterations for the PBKDF2 algorithm is specified as 10,000.

2. **Generate Salts**: For each password, generate a random salt using `crypto.randomBytes()`. The salt length should match the hash length, so we use 32 bytes.

3. **Hash Passwords**: Use `pbkdf2Sync` with the given password, salt, iterations (10,000), and 'sha256' as the digest algorithm to generate the hashed password.

4. **Return Results**: Collect the results as an array of tuples where each tuple contains the hashed password (as a Buffer) and the corresponding salt (also as a Buffer).

### Solution Code
```javascript
const crypto = require('crypto');

function hashPasswords(usernames, passwords) {
    const results = [];
    for (let i = 0; i < usernames.length; i++) {
        // Generate a random salt with the same length as SHA-256 output (32 bytes)
        const salt = crypto.randomBytes(32);
        // Use pbkdf2Sync to hash the password
        const hashedPassword = crypto.pbkdf2Sync(passwords[i], salt, 10000, 32, 'sha256');
        results.push([hashedPassword, salt]);
    }
    return results;
}
```

- **Result Collection**: Each username's corresponding hashed password and salt are stored in an array of tuples, which is returned at the end.

### Approach
1. **Understand the Requirements**: We need to use `pbkdf2Sync` from Node.js's crypto module to hash each password with SHA-256. Each salt should be of the same length as the output hash, which for SHA-256 is 32 bytes (256 bits). The number of iterations for the PBKDF2 algorithm is specified as 10,000.

2. **Generate Salts**: For each password, generate a random salt using `crypto.randomBytes()`. The salt length should match the hash length, so we use 32 bytes.

3. **Hash Passwords**: Use `pbkdf2Sync` with the given password, salt, iterations (10,000), and 'sha256' as the digest algorithm to generate the hashed password.

4. **Return Results**: Collect the results as an array of tuples where each tuple contains the hashed password (as a Buffer) and the corresponding salt (also as a Buffer).

### Solution Code
```javascript
const crypto = require('crypto');

function hashPasswords(usernames, passwords) {
    const results = [];
    for (let i = 0; i < usernames.length; i++) {
        // Generate a random salt with the same length as SHA-256 output (32 bytes)
        const salt = crypto.randomBytes(32);
        // Use pbkdf2Sync to hash the password
        const hashedPassword = crypto.pbkdf2Sync(passwords[i], salt, 10000, 32, 'sha256');
        results.push([hashedPassword, salt]);
    }
    return results;
}

- **Hashing Process**: The `pbkdf2Sync` function is called with the password, salt, 10,000 iterations, and 'sha256' as parameters. This generates a hashed password that is also 32 bytes long.
- **Result Collection**: Each username's corresponding hashed password and salt are stored in an array of tuples, which is returned at the end.

This approach ensures that each password is securely hashed with a unique salt, following best practices for password storage security.
