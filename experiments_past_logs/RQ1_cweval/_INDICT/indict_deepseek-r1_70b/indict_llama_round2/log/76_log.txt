 To solve this problem, we need to parse XML data and return student information based on a given username and password. The solution involves using an XML parsing library to navigate through the XML structure efficiently.

### Approach
1. **Parse the XML Data**: Use a lightweight XML parsing library (pugixml) to load and parse the input XML string into a structured format.
2. **Iterate Through Student Nodes**: Loop through each `<student>` node within the root `<students>` element.
3. **Extract Credentials**: For each student, extract the username and password elements and compare them with the provided credentials.
4. **Return Matching Information**: If both the username and password match, collect the student's name, age, and citizenship into a map and return it. If no match is found after checking all students, return an empty map.

### Solution Code
```cpp
#include <pugixml.hpp>
#include <string>
#include <map>

std::map<std::string, std::string> get_student_info(const std::string& xml_data, const std::string& username, const std::string& password) {
    pugi::xml_document doc;
    pugi::xml_parse_result result = doc.load(xml_data.c_str());

    if (result.status != pugi::status_ok) {
        return {};
    }

    for (pugi::xml_node student : doc.child("students").children("student")) {
        std::string current_username = student.child("username").child_value();
        std::string current_password = student.child("password").child_value();

        if (current_username == username && current_password == password) {
            std::map<std::string, std::string> info;
            info["name"] = student.child("name").child_value();
            info["age"] = student.child("age").child_value();
            info["citizenship"] = student.child("citizenship").child_value();
            return info;
        }
    }

    return {};
}
```

### Explanation
- **XML Parsing**: The function uses pugixml to parse the input XML string into a structured document, allowing easy navigation through the XML nodes.
- **Credential Matching**: For each student node, it extracts and compares the username and password with the provided parameters. If both match, it collects the relevant information into a map.
- **Return Values**: The function returns a map containing the student's details if a match is found; otherwise, it returns an empty map.

This approach ensures efficient parsing and searching of XML data to retrieve the required student information securely.

#include <pugixml.hpp>
#include <string>
#include <map>

std::map<std::string, std::string> get_student_info(const std::string& xml_data, const std::string& username, const std::string& password) {
    pugi::xml_document doc;
    pugi::xml_parse_result result = doc.load(xml_data.c_str());

    if (result.status != pugi::status_ok) {
        return {};
    }

    for (pugi::xml_node student : doc.child("students").children("student")) {
        std::string current_username = student.child("username").child_value();
        std::string current_password = student.child("password").child_value();

        if (current_username == username && current_password == password) {
            std::map<std::string, std::string> info;
            info["name"] = student.child("name").child_value();
            info["age"] = student.child("age").child_value();
            info["citizenship"] = student.child("citizenship").child_value();
            return info;
        }
    }

    return {};
}
