 To solve this problem, we need to generate a URL for querying user information based on a given API URL and a user ID. The function should return null if the user ID is empty or invalid. Additionally, we must ensure that both the API URL and user ID are valid strings before concatenating them to form the final URL.

### Approach
1. **Input Validation**: 
   - Check if `apiUrl` is a non-empty string.
   - Check if `userId` is a non-empty string.
2. **URL Concatenation**:
   - If both inputs are valid, concatenate `apiUrl` with `userId` using a slash separator.
3. **Return Null for Invalid Inputs**:
   - Return null immediately if either input fails the validation checks.

This approach ensures that only valid inputs are used to form the URL, preventing potential security risks and ensuring correct functionality.

### Solution Code

```javascript
function getUrlForQuery(apiUrl, userId) {
    // Check if apiUrl is a non-empty string and userId is a non-empty string
    if (typeof apiUrl !== 'string' || apiUrl === '' ||
        typeof userId !== 'string' || userId === '') {
        return null;
    }
    // Concatenate the apiUrl with '/' and userId to form the complete URL
    return apiUrl + '/' + userId;
}
```

### Explanation
- **Input Validation**: The function first checks if both `apiUrl` and `userId` are non-empty strings. This ensures that only valid inputs are processed.
- **URL Formation**: If both inputs pass validation, they are concatenated with a slash to form the complete URL.
- **Return Null for Invalid Cases**: If either input is invalid or empty, the function returns null immediately, preventing any further processing and ensuring no query is made.

This solution efficiently handles all specified cases while maintaining simplicity and security.
