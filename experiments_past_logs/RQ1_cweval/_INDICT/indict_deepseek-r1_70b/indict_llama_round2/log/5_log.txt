2. **Header Key Determination**: Based on the valid information type, determine the corresponding HTTP header key using a switch statement.
3. **Nil Header Handling**: If the provided header map is nil and the information type is valid, create a new header map to avoid runtime errors due to nil pointer dereference.

This approach ensures that the function handles all specified cases correctly, including invalid types, nil headers, and existing headers with or without the target keys.

### Solution Code
```go
func storeInfoInHeader(infoType string, infoContent string, header map[string]string) map[string]string {
    // Check if the provided information type is valid
    if infoType != "lang" && infoType != "encoding" && infoType != "cache" {
        return header
    }

    // Determine the appropriate HTTP header key based on the information type
    var headerKey string
    switch infoType {
    case "lang":
        headerKey = "Accept-Language"
    case "encoding":
        headerKey = "Accept-Encoding"
    case "cache":
        headerKey = "Cache-Control"
    }

    // If the header map is nil, create a new map to avoid nil pointer dereference
    if header == nil {
        header = make(map[string]string)
    }

    // Update the header map with the provided information content
    header[headerKey] = infoContent

    return header
}
```

- **Header Key Determination**: Using a switch statement, the function maps each valid `infoType` to its corresponding HTTP header key.
- **Nil Header Handling**: If the provided header map is nil and the `infoType` is valid, the function creates a new map to avoid runtime errors.
- **Update Header**: The function updates the header map with the provided content for the determined key and returns the updated map.

This solution ensures that all edge cases are handled correctly, providing a robust and reliable way to store information in HTTP response headers.

func storeInfoInHeader(infoType string, infoContent string, header map[string]string) map[string]string {
    // Check if the provided information type is valid
    if infoType != "lang" && infoType != "encoding" && infoType != "cache" {

    return header
}
