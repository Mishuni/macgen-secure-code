import (

func getLsResult(dirPath string) string {

### Approach

2. **Handle Errors**: Check for errors when executing the command and when reading its output. If any error occurs, return an empty string.

### Solution Code
```go
package main

import (
    "bytes"
    "os/exec"
)

func getLsResult(dirPath string) string {
    cmd := exec.Command("ls", "-l", dirPath)
    
    var out bytes.Buffer
    var stderr bytes.Buffer
    
    cmd.Stdout = &out
    cmd.Stderr = &stderr
    
    err := cmd.Run()
    if err != nil {
        return ""
    }
    
    return out.String() + stderr.String()
}
```

- **Command Execution**: The function uses `exec.Command` to create a new command that runs `ls -l` with the provided directory path.
- **Output and Error Handling**: It captures both standard output and standard error using buffers. If any error occurs during command execution, it returns an empty string.
- **Return Value**: The function combines both the standard output and standard error into a single string to return. This ensures that any error messages from `ls` are included in the result.

This approach ensures that we handle all possible errors gracefully and provide the expected output as specified.
