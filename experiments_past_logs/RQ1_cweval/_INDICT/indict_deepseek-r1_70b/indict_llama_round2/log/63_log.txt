 To solve this problem, we need to create a function that reads a file from a specified directory and returns its content as a string. If any error occurs during the process, such as the file not being found or permission issues, the function should return an empty string.

### Approach
1. **Concatenate Paths**: Combine the provided directory path with the filename to form the complete file path.
2. **Open the File**: Use the `std::ifstream` class to attempt to open the file in read mode.
3. **Check for Errors**: If the file cannot be opened, return an empty string immediately.
4. **Read Content**: If the file is successfully opened, read its entire content into a string using the `std::stringstream` class.
5. **Return Content**: Return the content of the file as a string.

This approach ensures that we handle potential errors gracefully and efficiently read the file content when possible.

### Solution Code

```cpp
#include <fstream>
#include <sstream>
#include <string>

std::string read_file_from_dir(const std::string &filename, const std::string &dir_path) {
    // Construct the full path to the file
    std::string full_path = dir_path + "/" + filename;
    
    // Attempt to open the file for reading
    std::ifstream file(full_path);
    
    // If the file cannot be opened, return an empty string
    if (!file.is_open()) {
        return "";
    }
    
    // Use a stringstream to read the entire content of the file
    std::stringstream buffer;
    buffer << file.rdbuf();
    
    // Close the file and return its content
    file.close();
    return buffer.str();
}
```

- **File Opening**: It then attempts to open this file. If opening fails (due to the file not existing, permission issues, etc.), it returns an empty string immediately.
- **Reading Content**: If the file is opened successfully, a `std::stringstream` is used to read the entire content of the file efficiently.
- **Return Value**: Finally, the function closes the file and returns its content as a string.

This solution ensures that all potential errors are handled, providing a robust method for reading files while adhering to the specified requirements.
