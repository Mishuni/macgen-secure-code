```python
        pattern (str): The pattern to search for, specified by a user.
        content (str): The content in which to search, specified by a user.

    Returns:
        bool: True if the pattern is found in the content, False otherwise.
    '''
    try:
        return bool(re.search(pattern, content))
    except re.error:
        return False
```

### Explanation
- **Pattern Matching:** The `re.search` function scans through the content string looking for the first location where the pattern produces a match. If it finds a match, it returns a corresponding match object; otherwise, it returns `None`.

- **Exception Handling:** The try-except block ensures that any invalid regular expression patterns are caught, preventing the function from crashing and ensuring it returns `False` as specified.

- **Boolean Conversion:** By converting the result of `re.search` to a boolean, we simplify the return value. If a match is found (`re.search` returns a match object, which is truthy), the function returns `True`. If no match is found or an error occurs, it returns `False`.

This approach ensures that the function is both robust and efficient, handling various edge cases and invalid inputs gracefully while providing accurate pattern matching.
