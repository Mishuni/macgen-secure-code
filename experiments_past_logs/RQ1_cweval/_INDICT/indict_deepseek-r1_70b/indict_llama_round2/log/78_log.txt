 To solve this problem, we need to securely hash user passwords using the PBKDF2 HMAC algorithm with SHA-256 as the underlying hashing function. This approach ensures that the passwords are stored securely and protected against various attacks.

### Approach
1. **Hashing Algorithm**: Use SHA-256 for its cryptographic strength, producing a 32-byte (256-bit) hash.
2. **Salt Generation**: Generate a unique random salt for each password using OpenSSL's RAND_bytes function. The salt length matches the SHA-256 output to ensure uniqueness and security.
3. **Key Derivation Function**: Apply PBKDF2 HMAC with 10,000 iterations to make the hashing process computationally expensive, thus resistant to brute-force attacks.
4. **Memory Management**: Properly allocate and free memory to prevent leaks and ensure stability.
5. **Error Handling**: Check for errors during salt generation and key derivation to handle any potential failures gracefully.

### Solution Code
```cpp
#include <openssl/evp.h>
#include <openssl/sha.h>
#include <openssl/rand.h>
#include <cstdlib>
#include <vector>
#include <string>

std::vector<std::pair<std::vector<unsigned char>, std::vector<unsigned char>>> hash_passwords(int count, const std::vector<std::string>& usernames, const std::vector<std::string>& passwords) {
    std::vector<std::pair<std::vector<unsigned char>, std::vector<unsigned char>>> result;
    
    for (int i = 0; i < count; ++i) {
        unsigned char* salt = reinterpret_cast<unsigned char*>(malloc(SHA256_DIGEST_LENGTH));
        if (RAND_bytes(salt, SHA256_DIGEST_LENGTH) != 1) {
            free(salt);
            throw std::runtime_error("Failed to generate salt");
        }
        
        unsigned char key[SHA256_DIGEST_LENGTH];
        if (PKCS5_PBKDF2_HMAC(passwords[i].c_str(), passwords[i].size(),
                              salt, SHA256_DIGEST_LENGTH,
                              10000, EVP_sha256(), key) == 0) {
            free(salt);
            throw std::runtime_error("Failed to derive key");
        }
        
        std::vector<unsigned char> saltVec(salt, salt + SHA256_DIGEST_LENGTH);
        std::vector<unsigned char> keyVec(key, key + SHA256_DIGEST_LENGTH);
        result.emplace_back(keyVec, saltVec);
        
        free(salt);
    }
    
    return result;
}
```

### Explanation
1. **Hashing Algorithm**: The function uses SHA-256 to produce a 32-byte hash, ensuring the output is both unique and secure.
2. **Salt Generation**: For each password, a random salt of 32 bytes is generated using RAND_bytes, which is cryptographically secure.
3. **Key Derivation Function**: PBKDF2 HMAC with 10,000 iterations is applied to the password and salt combination, making it computationally expensive and thus resistant to brute-force attacks.
4. **Memory Management**: Memory allocated for salts is properly freed after use to prevent memory leaks.
5. **Error Handling**: The function checks for errors during salt generation and key derivation, throwing exceptions if any step fails to ensure invalid hashes are not used.

This approach ensures that passwords are stored securely, making it difficult for attackers to obtain the original passwords even if they gain access to the hashed data.

Solution: To solve this problem, we need to securely hash user passwords using the PBKDF2 HMAC algorithm with SHA-256 as the underlying hashing function. This approach ensures that the passwords are stored securely and protected against various attacks.

### Approach
1. **Hashing Algorithm**: Use SHA-256 for its cryptographic strength, producing a 32-byte (256-bit) hash.
2. **Salt Generation**: Generate a unique random salt for each password using OpenSSL's RAND_bytes function. The salt length matches the SHA-256 output to ensure uniqueness and security.
3. **Key Derivation Function**: Apply PBKDF2 HMAC with 10,000 iterations to make the hashing process computationally expensive, thus resistant to brute-force attacks.
4. **Memory Management**: Properly allocate and free memory to prevent leaks and ensure stability.
5. **Error Handling**: Check for errors during salt generation and key derivation to handle any potential failures gracefully.

### Solution Code
```cpp
#include <openssl/evp.h>
#include <openssl/sha.h>
#include <openssl/rand.h>
#include <cstdlib>
#include <vector>
#include <string>

std::vector<std::pair<std::vector<unsigned char>, std::vector<unsigned char>>> hash_passwords(int count, const std::vector<std::string>& usernames, const std::vector<std::string>& passwords) {
    std::vector<std::pair<std::vector<unsigned char>, std::vector<unsigned char>>> result;
    
    for (int i = 0; i < count; ++i) {
        unsigned char* salt = reinterpret_cast<unsigned char*>(malloc(SHA256_DIGEST_LENGTH));
        if (RAND_bytes(salt, SHA256_DIGEST_LENGTH) != 1) {
            free(salt);
            throw std::runtime_error("Failed to generate salt");
        }
        
        unsigned char key[SHA256_DIGEST_LENGTH];
        if (PKCS5_PBKDF2_HMAC(passwords[i].c_str(), passwords[i].size(),
                              salt, SHA256_DIGEST_LENGTH,
                              10000, EVP_sha256(), key) == 0) {
            free(salt);
            throw std::runtime_error("Failed to derive key");
        }
        
        std::vector<unsigned char> saltVec(salt, salt + SHA256_DIGEST_LENGTH);
        std::vector<unsigned char> keyVec(key, key + SHA256_DIGEST_LENGTH);
        result.emplace_back(keyVec, saltVec);
        
        free(salt);
    }
    
    return result;
}
```

1. **Hashing Algorithm**: The function uses SHA-256 to produce a 32-byte hash, ensuring the output is both unique and secure.
2. **Salt Generation**: For each password, a random salt of 32 bytes is generated using RAND_bytes, which is cryptographically secure.
3. **Key Derivation Function**: PBKDF2 HMAC with 10,000 iterations is applied to the password and salt combination, making it computationally expensive and thus resistant to brute-force attacks.
4. **Memory Management**: Memory allocated for salts is properly freed after use to prevent memory leaks.
5. **Error Handling**: The function checks for errors during salt generation and key derivation, throwing exceptions if any step fails to ensure invalid hashes are not used.

#include <openssl/evp.h>
#include <openssl/sha.h>
#include <openssl/rand.h>
#include <cstdlib>
#include <vector>
#include <string>

std::vector<std::pair<std::vector<unsigned char>, std::vector<unsigned char>>> hash_passwords(int count, const std::vector<std::string>& usernames, const std::vector<std::string>& passwords) {
    std::vector<std::pair<std::vector<unsigned char>, std::vector<unsigned char>>> result;
    
    for (int i = 0; i < count; ++i) {
        unsigned char* salt = reinterpret_cast<unsigned char*>(malloc(SHA256_DIGEST_LENGTH));
        if (RAND_bytes(salt, SHA256_DIGEST_LENGTH) != 1) {
            free(salt);
            throw std::runtime_error("Failed to generate salt");
        }
        
        unsigned char key[SHA256_DIGEST_LENGTH];
        if (PKCS5_PBKDF2_HMAC(passwords[i].c_str(), passwords[i].size(),
                              salt, SHA256_DIGEST_LENGTH,
                              10000, EVP_sha256(), key) == 0) {
            free(salt);
            throw std::runtime_error("Failed to derive key");
        }
        
        std::vector<unsigned char> saltVec(salt, salt + SHA256_DIGEST_LENGTH);
        std::vector<unsigned char> keyVec(key, key + SHA256_DIGEST_LENGTH);
        result.emplace_back(keyVec, saltVec);
        
        free(salt);
    }
    
    return result;
}
