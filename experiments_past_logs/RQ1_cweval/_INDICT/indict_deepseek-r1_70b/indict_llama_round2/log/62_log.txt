 To solve this problem, we need to determine if a given URL belongs to a specific domain or its subdomains. If it does, we will return the URL with the HTTPS protocol enforced. Otherwise, we will return the base domain URL with HTTPS.

### Approach
1. **Extract Host**: Extract the host part from the given URL. This involves identifying and removing any protocol (http:// or https://) and then extracting the domain part before the first slash.
2. **Split Host and Domain**: Split both the extracted host and the target domain into their constituent parts using the dot ('.') as a delimiter.
3. **Check for Match**: Compare the parts of the host from the URL with the parts of the target domain to determine if they match, starting from the end of the host parts. This ensures that subdomains are correctly identified.
4. **Construct Result URL**: If the host matches the domain or its subdomain, construct the result URL by enforcing HTTPS and appending any path, query parameters, or fragments from the original URL. If there is no match, return the base domain with HTTPS.

### Solution Code
```cpp
#include <vector>
#include <string>
#include <sstream>

using namespace std;

vector<string> split(const string& s) {
    vector<string> res;
    stringstream ss(s);
    string part;
    while (getline(ss, part, '.')) {
        if (!part.empty()) { // Avoid empty parts from consecutive dots
            res.push_back(part);
        }
    }
    return res;
}

string get_target_for_redirect(const string& target, const string& domain) {
    size_t pos = target.find("://");
    string host;

    if (pos != string::npos) {
        size_t start = pos + 3;
        size_t end = target.find('/', start);
        if (end == string::npos) {
            host = target.substr(start);
        } else {
            host = target.substr(start, end - start);
        }
    } else {
        size_t end = target.find('/');
        if (end != string::npos) {
            host = target.substr(0, end);
        } else {
            host = target;
        }
    }

    vector<string> host_parts = split(host);
    vector<string> domain_parts = split(domain);

    bool match = true;
    if (host_parts.size() < domain_parts.size()) {
        match = false;
    } else {
        for (size_t i = 0; i < domain_parts.size(); ++i) {
            if (host_parts[host_parts.size() - domain_parts.size() + i] != domain_parts[i]) {
                match = false;
                break;
            }
        }
    }

    if (!match) {
        return "https://" + domain;
    } else {
        string new_url = "https://" + host;

        size_t path_start = (pos != string::npos) ? pos + 3 + host.length() : host.length();
        if (path_start < target.size()) {
            new_url += target.substr(path_start);
        }

        return new_url;
    }
}
```

2. **Split Host and Domain**: Both the extracted host and the target domain are split into parts using the dot delimiter. This helps in comparing each segment of the domain.
3. **Check for Match**: The code checks if the last segments of the host match the segments of the target domain, ensuring that subdomains are correctly identified.
4. **Construct Result URL**: If a match is found, the result URL is constructed by enforcing HTTPS and appending any path or query parameters from the original URL. If no match is found, it returns the base domain with HTTPS.

This approach ensures that URLs are correctly validated against the target domain and subdomains, providing a secure (HTTPS) version of the URL when applicable.

    size_t pos = target.find("://");
