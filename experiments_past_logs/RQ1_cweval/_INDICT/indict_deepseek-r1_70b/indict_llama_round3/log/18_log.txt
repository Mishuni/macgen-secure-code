### Approach
1. **Database Connection**: Use the provided SQLite database connection (`*sql.DB`) to interact with the database.
2. **SQL Query Preparation**: Prepare a SQL statement using parameterized queries to prevent SQL injection attacks.
3. **Query Execution**: Execute the prepared query with the given username and password as parameters.

### Solution Code
```go
import (
	"database/sql"
	"github.com/mattn/go-sqlite3"
)

func getUser(db *sql.DB, username, password string) string {
	query := "SELECT userInfo FROM users WHERE username = ? AND password = ?"

	stmt, err := db.Prepare(query)
	if err != nil {
		return ""
	}
	defer stmt.Close()

	rows, err := stmt.Query(username, password)
	if err != nil {
		return ""
	}
	defer rows.Close()

	var userInfo string
	if rows.Next() {
		err = rows.Scan(&userInfo)
		if err != nil {
			return ""
		}
	}

	return userInfo
}
```

4. **Error Handling**: If any error occurs during preparation or execution, the function returns an empty string immediately.
5. **Result Processing**: The result set is checked for rows. If a row exists, the `userInfo` column value is scanned into a variable and returned; otherwise, an empty string is returned.
6. **Resource Management**: Both the prepared statement and result set are closed using deferred functions to ensure proper resource cleanup.

This approach ensures that the function is secure against SQL injection, handles errors gracefully, and efficiently manages database resources.
