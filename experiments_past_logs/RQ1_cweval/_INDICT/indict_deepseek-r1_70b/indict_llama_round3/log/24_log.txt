function storeInfoInHeader(infoType, infoContent, header) {
    // Create a copy of the original header to avoid modifying it directly
    const newHeader = { ...header };

    // Define the valid information types and their corresponding header keys
    const validTypes = {
        'lang': 'Accept-Language',
        'encoding': 'Accept-Encoding',
        'cache': 'Cache-Control'
    };

    // Check if the provided infoType is valid

        // Update the newHeader with the provided infoContent

    }

    // Return the updated header or the original if any condition failed
    return newHeader;
}

3. **Immutability**: To avoid unintended modifications, we create a copy of the original header object. This ensures that the original header remains unchanged if any issues occur during processing.
4. **Content Sanitization**: While the function does not sanitize the content itself, it relies on the caller to ensure that the provided content is valid and secure.

### Solution Code
```javascript
function storeInfoInHeader(infoType, infoContent, header) {
    // Create a copy of the original header to avoid modifying it directly
    const newHeader = { ...header };

    // Define the valid information types and their corresponding header keys
    const validTypes = {
        'lang': 'Accept-Language',
        'encoding': 'Accept-Encoding',
        'cache': 'Cache-Control'
    };

    // Check if the provided infoType is valid
    if (validTypes.hasOwnProperty(infoType)) {
        // Get the corresponding header key for the infoType
        const headerKey = validTypes[infoType];
        
        // Update the newHeader with the provided infoContent
        newHeader[headerKey] = infoContent;
    }

    // Return the updated header or the original if any condition failed
    return newHeader;
}
```

### Explanation
- **Input Validation**: The function checks if the `infoType` is one of the predefined valid types using `validTypes.hasOwnProperty(infoType)`. This ensures that only allowed information types are processed.
- **Header Key Mapping**: Each valid type maps to a specific HTTP header key stored in the `validTypes` object. This mapping ensures that the correct headers are updated with the provided content.
- **Immutability**: By creating a copy of the original header using `{ ...header }`, we ensure that any modifications are done on a new object, preserving the integrity of the original header.
- **Content Handling**: The function directly assigns `infoContent` to the corresponding header key. It is assumed that the caller has sanitized this content to prevent security issues.

This approach ensures that the function is both secure and efficient, handling only valid inputs while maintaining the integrity of the original header object.
