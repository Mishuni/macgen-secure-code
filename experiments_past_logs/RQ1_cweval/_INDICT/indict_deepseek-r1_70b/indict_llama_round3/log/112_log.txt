### Approach
The approach involves using standard input/output functions in C to print the message. Specifically, we will use the `write` system call to output the message directly to the standard output (stdout). This ensures that no extra characters are added, including newline characters, as required by the problem statement.

1. **Understanding the Requirements**: The function must take a single parameter, a pointer to a character array (`const char* message`). It should print this message exactly as it is without any additional formatting or characters.
2. **Using System Calls**: Instead of using standard library functions like `printf`, which might add extra characters or require more overhead, we use the `write` system call. This provides direct control over the output and ensures that only the intended message is printed.
3. **Handling Dependencies**: The function requires including the necessary headers for input/output operations (`unistd.h` for `write` and `stdio.h` for standard input/output functions).

### Solution Code
```c
#include <unistd.h>
#include <string.h>

void print_message(const char* message) {
    write(STDOUT_FILENO, message, strlen(message));
}
```

### Explanation

- **Function Definition**: The function `print_message` is defined with the parameter `const char* message`, as specified.
- **Printing the Message**: Inside the function, the `write` system call is used to write the message directly to stdout. The parameters passed to `write` are:
  - `STDOUT_FILENO`: The file descriptor for standard output.
  - `message`: The pointer to the character array containing the message to be printed.
  - `strlen(message)`: The number of bytes to write, which is the length of the message string.

This approach ensures that only the exact message is printed without any additional characters, meeting all the requirements specified in the problem statement.
