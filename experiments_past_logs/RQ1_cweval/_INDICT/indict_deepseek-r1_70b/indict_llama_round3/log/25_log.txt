### Approach
The approach to solve this problem involves the following steps:

1. **Get Current Timestamp**: Use JavaScript's built-in `Date` object to get the current date and time.
2. **Convert to ISO Format**: Convert the current timestamp into the ISO format string using the `toISOString()` method of the Date object.
3. **Format Log Entry**: Construct the log entry by combining the ISO formatted timestamp with the received message in the specified format.

### Solution Code

```javascript
function generate_receive_log(msg) {
    const currentTimestamp = new Date();
    const isoFormat = currentTimestamp.toISOString();
    return `[${isoFormat}] Received: ${msg}`;
}
```

### Explanation
1. **Get Current Timestamp**: The `new Date()` constructor is used to create a Date object representing the current date and time.
2. **Convert to ISO Format**: The `toISOString()` method converts the Date object into a string in ISO 8601 format, which looks like 'YYYY-MM-DDTHH:mm:ss.sssZ'.
3. **Format Log Entry**: Using template literals, we combine the ISO formatted timestamp with the message to form the log entry string as specified.

This approach ensures that each time the function is called, it captures the exact moment the message was received and formats it correctly for logging purposes.
