 To solve this problem, we need to create a backend function that converts a YAML file into a JSON string. The function should handle various potential errors gracefully and return appropriate error messages when necessary.

### Approach
The approach involves several key steps:
1. **Reading the File**: Use Node.js's `fs` module to read the contents of the YAML file from the specified path.
2. **Parsing YAML Content**: Utilize a YAML parsing library (such as `js-yaml`) to convert the YAML content into a JavaScript object.
3. **Converting to JSON**: Convert the parsed JavaScript object into a JSON string using `JSON.stringify`.
4. **Error Handling**: Catch and handle any errors that occur during file reading, YAML parsing, or JSON conversion, ensuring appropriate error messages are returned.

### Solution Code
```javascript
const fs = require('fs');
const jsYaml = require('js-yaml');

function yaml_to_json(yamlFilePath) {
    try {
        const yamlContent = fs.readFileSync(yamlFilePath, 'utf8');
        const yamlObject = jsYaml.load(yamlContent);
        const jsonString = JSON.stringify(yamlObject);
        return jsonString;
    } catch (error) {
        if (error.code === 'ENOENT') {
            return `Error: File '${yamlFilePath}' not found.`;
        } else if (error instanceof jsYaml.YAMLException) {
            return `Error: Invalid YAML content - ${error.message}`;
        } else {
            return `Error: Failed to convert YAML to JSON - ${error.message}`;
        }
    }
}
```

### Explanation
1. **Reading the File**: The function uses `fs.readFileSync` to read the file synchronously, ensuring that any errors during reading (like a missing file) are caught immediately.
2. **Parsing YAML Content**: The `jsYaml.load` method parses the YAML content into a JavaScript object. If the YAML is invalid, this method throws a specific error (`YAMLException`) which we catch and handle.
3. **Converting to JSON**: The parsed object is then converted into a JSON string using `JSON.stringify`. This step can also throw errors if the object cannot be serialized, though such cases are rare with valid YAML content.
4. **Error Handling**: The function uses a try-catch block to catch any errors during the process. Specific error messages are constructed based on the type of error encountered, providing clear feedback for debugging.

This approach ensures that all potential issues are handled gracefully, and meaningful error messages are returned to help diagnose problems when they occur.

function yaml_to_json(yamlFilePath) {

        }
    }
}
