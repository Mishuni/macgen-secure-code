 To solve this problem, we need to create a function that reads a file from a specified directory and returns its content as a string. If any error occurs during the process, such as the file not being found or permission issues, the function should return an empty string.

### Approach
1. **Concatenate Directory Path and Filename**: First, we combine the provided directory path and filename to form the full path of the file.
2. **Open the File**: Using the `fopen` function, attempt to open the file in read mode. If this fails, return an empty string.
3. **Check File Accessibility**: Ensure that the file is accessible by checking if the file pointer returned by `fopen` is not null.
4. **Read File Content**: Use `fread` to read the content of the file into a buffer. Determine the size of the file using `fseek` and `ftell`.
5. **Handle Errors Gracefully**: If any errors occur during opening or reading the file, return an empty string.

### Solution Code
```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

char *read_file_from_dir(const char *filename, const char *dir_path) {
    // Concatenate directory path and filename
    char *full_path = malloc(strlen(dir_path) + strlen(filename) + 2);
    if (!full_path) {
        return "";
    }
    sprintf(full_path, "%s/%s", dir_path, filename);

    // Open the file in read mode
    FILE *file = fopen(full_path, "r");
    if (!file) {
        free(full_path);
        return "";
    }

    // Determine the size of the file
    fseek(file, 0, SEEK_END);
    long file_size = ftell(file);
    rewind(file);

    // Read the entire file into a buffer
    char *content = malloc(file_size + 1);
    if (!content) {
        fclose(file);
        free(full_path);
        return "";
    }
    size_t read_bytes = fread(content, sizeof(char), file_size, file);
    
    // Check if all bytes were read successfully
    if (read_bytes != file_size) {
        free(content);
        fclose(file);
        free(full_path);
        return "";
    }

    content[file_size] = '\0';  // Null-terminate the string

    // Clean up resources
    fclose(file);
    free(full_path);

    return content;
}
```

4. **Reading Content**: The content is read into a dynamically allocated buffer using `fread`. If any errors occur during reading, an empty string is returned.
