To solve this problem, we need to generate a URL for querying user information based on a given API URL and a user ID. The function should return the concatenated URL if the user ID is valid (non-empty), otherwise it returns an empty string.

### Approach
1. **Check User ID Validity**: First, determine if the provided user ID is empty. If it is, return an empty string immediately as no query will be made.
2. **Concatenate API URL and User ID**: If the user ID is valid (non-empty), concatenate it with the given API URL. Ensure there is exactly one slash (`/`) between the API URL and the user ID:
   - If the API URL already ends with a slash, append the user ID directly.
   - If the API URL does not end with a slash, add a slash before appending the user ID.

This approach ensures that the resulting URL is correctly formatted regardless of whether the API URL ends with a slash or not.

### Solution Code
```cpp
#include <string>

using namespace std;

std::string get_url_for_query(const std::string& api_url, const std::string& user_id) {
    if (user_id.empty()) {
        return "";
    }
    
    string new_url = api_url;
    if (!new_url.empty() && new_url.back() != '/') {
        new_url += '/';
    }
    new_url += user_id;
    
    return new_url;
}
```

### Explanation
- **Check for Empty User ID**: The function first checks if the `user_id` is empty. If it is, the function returns an empty string.
- **Concatenation Logic**: 
  - If the API URL (`api_url`) does not end with a slash, a slash is added before appending the `user_id`.
  - If the API URL already ends with a slash, the `user_id` is appended directly without adding an extra slash.
  
This ensures that the resulting URL is always correctly formatted, whether or not the API URL ends with a slash. This approach handles all edge cases, such as empty user IDs and varying endings of the API URL.

### Solution Code
```cpp
#include <string>

using namespace std;

std::string get_url_for_query(const std::string& api_url, const std::string& user_id) {
    if (user_id.empty()) {
        return "";
    }
    
    string new_url = api_url;
    if (!new_url.empty() && new_url.back() != '/') {
        new_url += '/';
    }
    new_url += user_id;
    
    return new_url;
}
```

  - If the API URL already ends with a slash, the `user_id` is appended directly without adding an extra slash.

std::string get_url_for_query(const std::string& api_url, const std::string& user_id) {

}
