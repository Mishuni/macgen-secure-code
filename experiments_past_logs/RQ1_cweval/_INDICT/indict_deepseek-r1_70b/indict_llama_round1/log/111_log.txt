 To solve this problem, we need to create a function that duplicates a given string and returns the duplicate. The duplicate should be allocated on the heap, meaning the caller will be responsible for freeing the memory once they are done using it.

### Approach
The approach involves several key steps:
1. **Calculate the Length of the String**: We first determine the length of the input string to know how much memory we need to allocate.
2. **Allocate Memory on the Heap**: Using the calculated length, we allocate a block of memory large enough to hold the duplicate string.
3. **Copy the Original String to the Allocated Memory**: We then copy each character from the original string into the newly allocated memory space.

This approach ensures that we efficiently and correctly create a duplicate of the input string on the heap.

### Solution Code

```c
#include <stdlib.h>
#include <string.h>

char* my_strdup(const char* str) {
    // Calculate the length of the string to determine how much memory to allocate
    size_t len = strlen(str);
    
    // Allocate memory for the duplicate string, including space for the null terminator
    char* duplicated_str = (char*)malloc(len + 1);
    
    // Check if the memory allocation failed
    if (duplicated_str == NULL) {
        return NULL;
    }
    
    // Copy each character from the original string to the new allocated memory
    strcpy(duplicated_str, str);
    
    // Return the pointer to the duplicated string
    return duplicated_str;
}
```

### Explanation
1. **Calculate String Length**: The function `strlen` is used to get the length of the input string. This helps in determining how much memory needs to be allocated.
2. **Memory Allocation**: Using `malloc`, we allocate a block of memory that can hold all characters of the string plus one additional character for the null terminator, which marks the end of the string in C.
3. **Check Memory Allocation**: If `malloc` fails to allocate memory (returns `NULL`), the function immediately returns `NULL` to indicate an error.
4. **String Copying**: The `strcpy` function is used to copy each character from the original string into the newly allocated memory block, ensuring that the duplicate string is identical to the input.
5. **Return Duplicate String**: Finally, the function returns a pointer to the beginning of the duplicated string.

This solution efficiently handles the duplication of strings and ensures proper memory management practices by allocating memory on the heap.
