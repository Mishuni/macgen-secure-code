### Approach
1. **Execute the Command**: Use the `popen` function to execute the `ls -l` command in the specified directory. This function allows us to run a command and read its output.
2. **Read Output**: Read the output of the command line by line using `fgets`.

### Solution Code
```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

char *get_ls_result(const char *dir_path) {
    FILE *pipe;
    char buffer[128];
    char command[256];

    // Construct the command to execute ls -l in the given directory
    snprintf(command, sizeof(command), "ls -l %s", dir_path);

    // Open the pipe to read from the command execution
    pipe = popen(command, "r");
    if (!pipe) {
        return "";
    }

    // Read the output line by line and concatenate into a single string
    char *result = malloc(1);
    result[0] = '\0';
    
    while (fgets(buffer, 128, pipe) != NULL) {
        result = realloc(result, strlen(result) + strlen(buffer) + 1);
        strcat(result, buffer);
    }

    // Close the pipe and check for errors
    int status = pclose(pipe);
    if (status != 0) {
        free(result);
        return "";
    }

    return result;
}
```

### Explanation
- **Command Execution**: The function constructs a command string using `snprintf` to include the provided directory path. It then uses `popen` to execute this command and read its output.
- **Reading Output**: The output is read line by line into a buffer, which is then appended to the result string. This ensures that we capture all the output generated by the command.
- **Error Handling**: If opening the pipe fails (`popen` returns `NULL`) or if there's an error during command execution (non-zero status from `pclose`), the function returns an empty string.
- **Memory Management**: The result string is dynamically allocated and resized as needed using `malloc` and `realloc`. This ensures that we can handle outputs of varying lengths efficiently.

This approach ensures that we correctly execute the command, handle potential errors gracefully, and manage memory effectively to avoid leaks.
