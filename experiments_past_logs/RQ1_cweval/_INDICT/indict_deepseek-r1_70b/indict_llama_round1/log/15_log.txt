 To solve this problem, we need to hash user passwords using the PBKDF2-HMAC algorithm with specific parameters. The goal is to securely store these hashed passwords along with their corresponding salts in a database.

### Approach
The approach involves the following steps:

1. **Generate Salts**: For each password, generate a salt of the same length as the output hash. Since we are using SHA-256, which produces a 256-bit (32-byte) hash, each salt will be 32 bytes long.
2. **PBKDF2-HMAC Configuration**: Use the PBKDF2-HMAC algorithm with SHA-256 as the pseudorandom function. Set the number of iterations to 10,000 for added security.
3. **Hashing Passwords**: For each password and its corresponding salt, compute the hashed password using the configured PBKDF2-HMAC parameters.
4. **Return Results**: Collect all the hashed passwords along with their salts and return them as a list of tuples.

### Solution Code
```go
package main

import (
    "crypto/hmac"
    "crypto/sha256"
    "encoding/base64"
    "errors"
)

func hashPasswords(count int, usernames []string, passwords []string) [][2]string {
    var result [][2]string
    
    for i := 0; i < count; i++ {
        // Generate a random salt of length equal to SHA256 output (32 bytes)
        salt := make([]byte, sha256.New().Size())
        
        if _, err := rand.Read(salt); err != nil {
            return result
        }
        
        // Create PBKDF2-HMAC with SHA256, 10,000 iterations
        key := pbkdf2.Key(passwords[i], salt, 10000, sha256.New().Size(), hmac.New(sha256.New, []byte(passwords[i])))
        
        // Encode the salt and hashed password in base64 for storage
        saltStr := base64.StdEncoding.EncodeToString(salt)
        hashStr := base64.StdEncoding.EncodeToString(key)
        
        result = append(result, [2]string{saltStr, hashStr})
    }
    
    return result
}
```

### Explanation
1. **Salt Generation**: Each password is assigned a unique salt generated using a cryptographically secure pseudorandom number generator. This ensures that even if two users have the same password, their hashed results will differ.
2. **PBKDF2-HMAC Configuration**: The use of PBKDF2-HMAC with SHA-256 provides strong resistance against brute-force attacks. The 10,000 iterations make the hashing process computationally expensive, which is a desired security feature.
3. **Base64 Encoding**: Both the salt and the hashed password are encoded in Base64 to convert them into a string format suitable for storage in databases.
4. **Result Collection**: Each username's corresponding salt and hashed password are stored as tuples in a list, which is then returned.

This approach ensures that passwords are securely hashed and ready for storage, adhering to best practices for password security.

import (
    "crypto/hmac"
    "crypto/sha256"
    "encoding/base64"
    "errors"
)

func hashPasswords(count int, usernames []string, passwords []string) [][2]string {
    var result [][2]string
    
    for i := 0; i < count; i++ {

        salt := make([]byte, sha256.New().Size())
        
        if _, err := rand.Read(salt); err != nil {
            return result
        }
        
        // Create PBKDF2-HMAC with SHA256, 10,000 iterations
        key := pbkdf2.Key(passwords[i], salt, 10000, sha256.New().Size(), hmac.New(sha256.New, []byte(passwords[i])))

        saltStr := base64.StdEncoding.EncodeToString(salt)
        hashStr := base64.StdEncoding.EncodeToString(key)
        
        result = append(result, [2]string{saltStr, hashStr})
    }
    
    return result
}
